# Hanzi Hero · 汉字小英雄

> 给 5 岁孩子的中文识字游戏。纯前端、零依赖、断网可玩，电脑用鼠标、iPad 用触控都能玩。
>
> A mouse-friendly (and touch-friendly) Chinese literacy game for 5-year-olds. Pure HTML/CSS/JS, no build step, no backend, works offline.

**最省事的玩法：双击 `index.html`，用 Edge 或 Chrome 打开。** 想装到 iPad 上请看下面的「iPad / 手机安装」。

---

## 为什么又造一个识字游戏

市面上的识字 App 要么要联网、要么要付费、要么广告弹窗不断。这个项目的目标是：

- **打开就能玩** —— 没有账号、没有安装、没有联网请求
- **声音要好听** —— 系统自带的机械音孩子根本听不进去，所以把微软云的真人级女声
  **预生成成 848 条 mp3 塞进仓库**，离线也能听到"幼儿园老师讲故事"的质感
- **不逼孩子** —— 答错不会被惩罚，只会让这个字下次出现得更勤
- **数据不外传** —— 学习进度只存在浏览器 localStorage 里

## 功能

### 5 关 60 个常用字

| 关卡 | 主题 | 字 |
|---|---|---|
| 1 | 🔢 数字与身体 | 一二三四五六七八九十人口 |
| 2 | 🌈 天地大自然 | 日月水火山木土大小上下天 |
| 3 | 🏡 我的家和小动物 | 爸妈家门车鸟鱼牛羊马虫花 |
| 4 | 🎨 颜色和天气 | 中白红黑云雨风田米电手目 |
| 5 | 🎒 动作和上学 | 飞走看听说吃早好学书朋友 |

解锁第 6 关：家长可以在面板里加自己的字（幼儿园发的字表直接粘进去）。

### 4 种玩法

- 📖 **学一学** —— 大卡片看字，点一下听读音和组词
- 👂 **听音选字** —— 听到什么点什么
- 🎯 **找字游戏** —— 从 12 格里把藏起来的字找出来
- 🧩 **配对游戏** —— 把字和它的图片配成一对

### 穿插复习小游戏

连续答对几题就会蹦出一个小游戏换换脑子，三种皮肤随机：**🎈 戳气球 / 🐹 打地鼠 / 🍎 摘苹果**。
右下角有「跳过 ↪」，孩子不想玩随时跳过，不会被困住。

### 错题优先

孩子反复认错的字会被记下来，**出现权重按错次数加权**（错 1 次权重 ×5，错 2 次以上再加成）。
答对则让错次数自然衰减。实测：错 5 次的字出现率约 **53%**，而其他 11 个字平均 2.7%。

家长面板能看到「🔥 容易错的字」排行。

### 家长面板

右上角 👨‍👩‍👦 进入：

- 每个字的认识次数（颜色分级）+ 易错字排行
- 改孩子的名字（会显示在首页和结算页）
- **加自己的字**：一行一个，`字 拼音 词语`，拼音和配图会自动补
- 切换朗读声音（两张卡片，可试听）
- 解锁全部关卡 / 关声音 / 清空记录

## iPad / 手机安装（PWA）

游戏已做 **PWA 适配**：装到 iPad / iPhone / 安卓手机上，能像原生 App 一样全屏运行、有独立图标、
离线可玩（音频会自动缓存）。

**前提**：游戏得先放到一个 `https://` 地址上（比如 GitHub Pages），因为 iOS 只在 https 下允许
「添加到主屏幕」。拿到网址后：

| 设备 | 操作 |
|---|---|
| **iPad / iPhone（Safari）** | 打开网址 → 点右上角「分享」→「添加到主屏幕」→ 命名 → 添加 |
| **安卓（Chrome）** | 打开网址 → 菜单「⋮」→「添加到主屏幕 / 安装应用」 |

装好后从主屏幕图标进入，就是全屏无地址栏的独立应用了。

> ⚠️ 注意：**双击 `index.html`（`file://`）时不会启用 Service Worker**——这是浏览器安全限制，
> 不影响电脑上双击运行；PWA 离线缓存只在 https 下生效。触控适配本身（防双击缩放、防长按弹菜单、
> 去掉 iPad 悬停粘滞）在任何打开方式下都生效。

### 触控适配做了什么

- `touch-action: manipulation` + viewport 禁缩放 → 点按钮不再有 300ms 延迟、不会双击误缩放
- `user-select: none` / `-webkit-touch-callout: none` → 手指拖拽不会选中文字、长按不弹系统菜单
- 所有 `:hover` 效果包进 `@media (hover: hover) and (pointer: fine)` → iPad 上点一下不会「粘」在悬停态
- 大字按钮、大卡片布局 → 手指点得准

## 配音

游戏默认用**预生成的真人级云音频**（`audio/` 目录，848 条 mp3，8.7 MB），不走系统 TTS。

两个微软云普通话女声：

| 声音 | 风格 | 条数 |
|---|---|---|
| ☁️ 云朵姐姐（`zh-CN-XiaoxiaoNeural`） | 温柔甜美，默认 | 424 |
| 🌸 小樱姐姐（`zh-CN-XiaoyiNeural`） | 活泼可爱 | 424 |

系统自带的机械音（Huihui 等）只在云音频没覆盖到的生僻字上兜底。

**给新字补声音**：双击 `更新声音.bat`，把字粘进去回车即可（需要联网 + Python + edge-tts）。

```bash
pip install edge-tts
python gen_audio.py              # 补齐缺失的音频（已存在的会跳过）
python gen_audio.py --extra 猫狗 # 追加指定字
python gen_audio.py --force      # 全部重新生成
```

`gen_audio.py` 用 `edge-tts` 调微软 Edge 大声朗读用的同一个免费接口，不需要 API key。
单字放慢到 -20% 语速、音调 +12Hz，小朋友听得清也更亲切。

## 实现上值得一提的几个点

**1. 音频清单写成 JS 而不是 JSON。**
孩子是双击 `index.html` 用 `file://` 打开的，这个协议下 `fetch()` 读本地 JSON 会被 CORS 拦掉。
所以映射表输出成 `window.AUDIO_MANIFEST = {...};` 用 `<script>` 引入。

**2. 拼接朗读，而不是猜延时。**
念完字再念组词，早期用 `setTimeout(..., 1150)` 猜间隔，经常念到一半被切断或者念完空等。
改成 `speak(['一', '一个'])`，真的等上一条 mp3 `onended` 再播下一条。

**3. 音效是 Web Audio 现场合成的。**
星星、答对、答错、气球爆掉…… 全部用振荡器实时合成，不需要任何音频文件，也就不需要联网。

**4. 别把模块命名为 `Audio`。**
早期版本 `var Audio = {}` 把浏览器全局的 `Audio` 构造函数遮蔽了，`new Audio(url)` 抛错却被
`try/catch` 吞掉 —— 表现是"游戏正常但一点声音都没有"。现在模块内部叫 `GA`，对外导出
`window.GameAudio`。回归测试里有一条专门盯这个。

## 隐私

- 没有任何网络请求，没有后端，没有统计埋点
- 学习进度（星星、认识次数、错题、名字、自定义字）只存在浏览器的 localStorage
- 换浏览器或清缓存会丢进度 —— 这是纯本地应用的取舍，换来的是零隐私风险
